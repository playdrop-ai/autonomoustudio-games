# Flighty Saucer social short v3

Status: owner approved for YouTube Shorts, TikTok, and Instagram Reels.

This campaign keeps one shared 9:16 master. It uses two moments from one
continuous, truthful preview run:

1. a calm early flight through Dawn Meadow;
2. a late score-32 run through the faster desert environment, ending in a real
   gate crash.

The crash phase is slowed independently so the impact remains readable before
the protected hero end card fades in. Gameplay rules, difficulty, obstacles,
collisions, input cues, and score progression are unchanged.

## Files

- `source-captures/portrait-final/listing.mp4`: complete 47.38-second real
  portrait preview take.
- `project/brief.md`: locked creative direction.
- `project/edit-manifest.json`: exact source ranges, speeds, transitions, and
  output contract.
- `project/render-videos.mjs`: deterministic render recipe.
- `final/flighty-saucer-social-short-portrait-9x16-en-US.mp4`: approved shared
  social master.
- `review/final/`: opening, ending, complete, tap-cue, and crash review frames.

The protected hero remains unchanged. The final gameplay is HUD-free, uses the
approved cartoon hand for every real thrust, and contains no generated
gameplay, crop, padding, bars, or nonuniform scaling.
