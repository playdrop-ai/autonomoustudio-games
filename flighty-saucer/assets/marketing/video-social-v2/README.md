# Flighty Saucer video campaign v2

Hero-led portrait and landscape edits built from real PlayDrop preview capture.

- `source-captures/portrait-final/`: exact 9:16 gameplay with synchronized game audio.
- `source-captures/landscape-final/`: exact 16:9 gameplay with synchronized game audio.
- `project/`: brief, edit manifest, and reproducible render script.
- `review/final/`: first and final frames, complete contact sheets, tap-cue sheets, and the multi-format review composite.
- `final/`: delivery videos and protected hero posters.

Rebuild with:

```sh
node assets/marketing/video-social-v2/project/render-videos.mjs
```

No asset in this package has been uploaded or published.
