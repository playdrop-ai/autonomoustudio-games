# Starfold marketing media

| Folder | Destination | Delivery |
| --- | --- | --- |
| `playdrop/` | PlayDrop game detail and catalogue | Portrait media is 9:16. Landscape media is 16:9. Only this folder is referenced by `catalogue.json`. |
| `app-store-custom-product-page/` | Apple Custom Product Page | Approved iPhone 6.9-inch portrait and iPad 13-inch landscape files at Apple's accepted device-specific sizes. |
| `applovin-interstitial/` | AppLovin paid interstitial campaigns | Portrait 1080x1920 H.264 videos and one 1080x1920 end card. |

The PlayDrop screenshots are deliberately reframed exports of the approved campaign compositions. The Apple originals remain unchanged. The PlayDrop `capture/` directory contains the earlier raw 9:16 and 16:9 gameplay captures.
